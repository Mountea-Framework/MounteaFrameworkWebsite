Mountea Dialoguer

Mountea Dialoguer is a browser-first conversation editor for writers, designers, and gameplay teams. Sketch narrative flow in a node graph, organize participants and categories, then export data ready for your production pipeline. This tool is made using React Flow and provides native import for Unreal Engine. However, other integrations are easy to implements thanks to mnteadlg and mnteadlgproj standardized exports from the tool.

Launch App

Visual authoring

Construct conversations with drag-and-drop nodes and clear edge flow, then iterate quickly without leaving the browser.

Project structure

Keep dialogue teams aligned with participant categories, metadata, and reusable project-level organization.

Export ready

Output dialogue datasets and supporting files that can be fed directly into gameplay implementation workflows.

Typical workflow

  1. Create or load a project.
  2. Define participants and categories.
  3. Author node flow and dialogue rows.
  4. Export files for integration and testing.
