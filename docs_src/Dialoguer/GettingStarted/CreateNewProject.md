# Create new project

Creating new project is fairly straightforward process. Let's get to it.

---

## 1. Setting Up Project Details

After naming your project, you’ll configure who speaks in your dialogue:

1. **Add Categories**
    - Write-in name of your new Category (eg. `NPC`)
    - In the **Participant Categories** list, click **+**
    - Then create child category (eg. `Blackmisth`)
        - Select parent category from list of categories
    - In the **Participant Categories** list, click **+**
2. **Add Participants**
    - Write-in name of your new Participant (eg. `Albert`)
    - Select **Category** this Participant belongs to (eg. `NPC`)
    - In the **Dialogue Participants** list, click **+**
3. **Edit or Remove**
    - Hover a category or participant to reveal **Edit** and **Delete** controls.

!!! info inline "Editable Later"
    All project settings (except the **Title**) are editable within the project itself. So don't worry about making mistakes or poorly named Categories now.

!!! question inline end "What are categories good for?"
    Categories are used to identify participants. In Unreal Engine those are translated to **Gameplay Tags**.
