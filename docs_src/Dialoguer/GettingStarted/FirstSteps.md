# Getting Started

This guide walks you through every step of designing, configuring, and exporting your dialogues with the **Mountea Dialoguer** online tool. All code is publicly available as open source repository.

---

## 1. New Project Setup

1. **Open the Dialoguer Tool**

   Navigate to the live version at [https://mountea-framework.github.io/MounteaDialoguer/](https://mountea-framework.github.io/MounteaDialoguer/).

2. **Landing Page: Create Project**

   * Click **New Project** on the landing page to invoke the `NewProject` component.
   * In the modal, enter your **Dialogue Name** (up to 64 characters).
   * Click **Create Project** to continue.
