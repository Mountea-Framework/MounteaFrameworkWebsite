# Exporting to `.mnteadlg`

Finalize your project into a single file for sharing or import.

## 1. Trigger Export

- Click the 💾 **Export** button in the toolbar.

## 2. What Gets Bundled

- **Metadata** (name, participants, categories)  
- **Nodes & Rows** (all text, order, links)  
- **Audio Files**
