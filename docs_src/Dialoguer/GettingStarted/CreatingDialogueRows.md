# Adding Dialogue Rows

Populate each node with the actual lines and media.

---

## 1. Select a Node

- Click a node to open its **Details** pane.

## 2. Add & Edit Rows

1. Under **Dialogue Rows**, click **+ Add Row**.  
2. Type the character’s line.  
3. Drag the ⋮⋮ handle to reorder.

## 3. Duration & Audio

- **Duration Slider**: adjust play‑time in milliseconds.  
- **Audio Upload**: click or drag‑and‑drop a voice‑over file.
