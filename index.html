Interaction System

Mountea Interaction

Open-source components-based tool for smart Actor Interaction with other Actors. Developed with Designers in mind to allow the easiest possible implementation while maintaining high scalability and extensive customization options.

The plugin ships with an in-engine interactive tutorial and a downloadable playable demo so you can see it working immediately. Comprehensive Quick Start docs, a full API reference on the GitHub Wiki, and a YouTube tutorial playlist guide you step by step. Dynamic input mapping automatically adjusts prompts and icons for keyboard, gamepad, or touch controls, and over ten ready-to-use widgets cover most gameplay scenarios.

An active Discord community offers live support and feedback.


Abandonned Engine Versions:
  • 4.25 - 4.27
Supported Engine Versions:
  • 5.0 - 5.5
WIP Engine Versions:
  • 5.6

Features:
  • Complete replication
  • Blueprint & C++ setup in under a minute
  • Interactive playable tutorial
  • 10+ ready-to-use interaction widgets
  • Dynamic input mapping & data-driven configuration

Dialogue System

Mountea Dialogue

Open-source Mountea Framework plugin for Unreal Engine that provides a visual dialogue graph editor plus built-in validation to catch errors before you ship..

Enjoy drag-and-drop node creation, contextual graph validations, custom themes, and live dialogue previews per participant instance. Blueprint-based decorators let you trigger cutscenes, camera switches, combat checks and more from any node. Ships with a playable demo, Quick Start guide in the GitHub Wiki and tutorial videos.

An active Discord community offers live support and feedback.

Advanced Inventory & Equipment

Mountea Inventory & Equipment

Mountea Inventory & Equipment is an open-source, component-based Unreal Engine plugin for building robust inventory and equipment systems without any prior code knowledge. It uses a data-driven approach for items, categories, crafting recipes, and equipment slots.

A suite of Editor Extensions lets you manage templates, categories, and presets directly in the Unreal Editor. Item Actions (consume, use, equip, etc.) appear in context menus and can be customized or extended via Blueprint or C++ APIs.

Comprehensive online documentation, Quick Start guides, tutorial videos and an active Discord community offers live support and feedback.


WIP Engine Versions:
  • 5.1

Features:
  • Data-driven item definitions
  • In-editor templates and category management
  • Customizable item Actions via context menu
  • Blueprint & C++ APIs for full extensibility

Dialoguer Tool

Mountea Dialoguer

Mountea Dialoguer is a free, open-source, browser-based dialogue editor designed for writers and developers. Its intuitive graph canvas lets you visualize and build complex conversation flows with drag-and-drop ease.

Manage participants and dialogue assets in one place and rely on auto-save to protect your work. Export to Unreal Engine asset, and tap into full documentation, tutorial videos, and live Discord support to get up to speed quickly.


Key Features:
  • Interactive Canvas: Create and edit dialogue nodes in a clear, graphical interface.
  • Participant Management: Add, categorize, and configure characters.
  • Project Management: Create, load, and switch between multiple dialogue projects.

Inventory Manager

Mountea Inventory Manager

Manage your game’s item database entirely in the browser—no Unreal Editor needed. Create, update and organize item templates with fields like name, description, rarity and value, then upload and preview icons or 3D meshes. Collaborate with teammates via export/import, and instantly publish your final templates back into Unreal Engine.


Key Features:
  • Visual template form for item name, GUID, description
  • Item property configuration: type, rarity, stack size, weight, value, durability
  • Flags & equipment toggles for template categorization
  • Manager visual assets (icons/meshes) for template assets
  • Import/export: fast communication to/from Unreal .mnteaitem/.mnteaitems files
  • Settings panel for categories, rarities, equipment slots
  • Live JSON preview & form validation
  • Keyboard shortcuts for rapid template management
