Game Director

A powerful plugin designed to manage complex gameplay systems such as quests, NPC behavior, and scheduling through intuitive, designer-friendly tools. Built for scalability and ease of use, Game Director puts control directly in your hands—no deep programming knowledge required.

Game Director includes a visual Behavior Tree editor, a modular Quest Tree system, and timeline-based NPC scheduling, allowing you to create dynamic, believable worlds with minimal setup. Whether you're building a branching narrative, an open-world simulation, or a linear mission-based experience, Game Director adapts to your needs.

Features like dynamic event triggering, reusable logic templates, and real-time debugging tools streamline development and empower you to focus on design, not boilerplate.

Includes an in-engine interactive tutorial, a playable demo and detailed Quick Start guides. Active Discord support community is available for feedback and assistance.

  • Fully replicated for multiplayer support
  • Data-driven configuration and localization support
