Project Launcher

Stop wrestling with command-line arguments—launch any Unreal project in one click with a clean, intuitive interface.

Pick or create launch profiles (server, client, standalone), switch between installed engine versions instantly, and preview your settings before you hit "Go."


Features:
  • One-click launch: select project, choose profile, hit "Launch"
  • Save and reuse custom presets for multiplayer, solo testing, or QA
  • Auto-detects all installed UE versions so you never hard-code engine paths
  • Live preview of command-line parameters for full transparency
