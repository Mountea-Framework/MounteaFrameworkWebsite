# **Mountea Dialogue Docs Are Live — Build Your First Conversation in 30 Minutes**

The full Mountea Dialogue System documentation is up and ready. It’s clear, practical, and built from real questions the community kept asking.

<!-- more -->
---

## Why this matters (and to whom)

If you’re making narrative games in Unreal, you no longer have to dig through scattered READMEs or guess how the plugin fits into a real project. The docs walk you from install to a working dialogue, then into the “clever stuff” like validation, decorators, and branching.

---

## Start here, fast

1. Open the **First Steps** guide.
2. Install, configure, and run your first dialogue in under half an hour.
3. Ship the prototype to your team.

That’s it. No mystery steps, no hidden settings.

---

## Power features, plain English

* **Graph Validator**: Catch broken links and bad data before you hit build.
* **Dialogue Decorators**: Add behaviors (cutscenes, conditions, triggers) without burying yourself in code.
* **Live Preview**: See what players will see—now, not after a compile.

Everything above is documented with real examples, not theory.

---

## Two tools, one workflow

You’ve got the Unreal plugin. And you’ve got [**Dialoguer**](https://mountea.tools/dialoguer), a browser-based editor for writers and designers.

* Write and structure dialogue in the web app.
* Export to Unreal.
* Layer runtime decorators and validation in-engine.

Narrative folks and programmers can finally move in parallel. Less blocking, more building.

## Install without the headache

* Code lives publicly on GitHub.
