We're thrilled to announce a powerful new feature in **Mountea Dialogue** — full support for **Condition** and **Event Nodes**!

This update unlocks a deeper layer of control and interactivity in your dialogue flows, allowing you to build branching conversations that **respond to game state, player choices, and scripted events**.

---

## 🎯 What's New

### ✅ **Condition Nodes**
You can now use `Condition Nodes` to:

- Check for inventory items
- Gate dialogue options behind quests or flags
- React to custom variables or scripts

All without needing to write a single line of hardcoded logic.

### ✅ **Event Nodes**
Trigger in-game actions directly from your dialogue tree:

- Play cutscenes or animations
- Grant rewards
- Change NPC behavior
- Trigger UnityEvents or custom scripts

---

## 🛠 How It Works

These nodes can be added and configured directly within the Dialogue Editor. Each one allows you to plug in components via Mountea’s modular system — keeping your game logic clean, scalable, and reusable.

If you’re using Mountea Runtime Variables or integrating with other Mountea Tools (like Inventory or Quest), everything connects seamlessly.
